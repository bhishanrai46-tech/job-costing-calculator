View on GitHub Get the app

What it does

Accurate costing

Labour, travel time, vehicle km, materials, other costs and overhead (percent or per hour).

Smart pricing

Target margin, minimum price, rounding, and a live “gut feel vs recommended” comparison.

Job library

Save, search, load, duplicate and delete jobs. Never lose a quote again.

Professional PDFs

Clean A4 quotes and tax invoices with deposit, payment terms and your branding.

Fully private

Everything stays on your computer. No account, no cloud, nothing is sent anywhere.

Cross-platform

Works on Windows, macOS and Linux. One Python file + optional ReportLab for PDF.

Install & run

  1. Install Python 3.9+ Download from python.org if you don’t already have it.
  2. Install the PDF library (only needed for export) 
    pip install reportlab
  3. Download and run 
    python job_costing_app.py
    Or clone the repo and run from there.

Data is saved automatically in ~/.job_costing/data.json. Use File → Export backup to keep a safe copy.
